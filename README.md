# `fabrishot`
A minimal Fabric port of [mineshot](https://github.com/ata4/mineshot) which supports high resolution screenshots

[CurseForge page](https://www.curseforge.com/minecraft/mc-mods/fabrishot)

[Modrinth page](https://modrinth.com/mod/fabrishot)

## Delayed 4K screenshots on Minecraft 1.21.11

Press **F9** with the screenshot size set to **3840 × 2160**. The 60-second wait starts after the first 4K frame. The game keeps rendering at 4K until Fabrishot takes the screenshot, then returns to the window's normal render size.
